# ititube

اپلیکیشن سفارش طراحی تامبنیل حرفه‌ای یوتیوب — سه زبانه (فارسی / انگلیسی / ترکی)، کیف‌پول داخلی، و ورود با گوگل یا ایمیل.

این یه پروژه‌ی **Vite + React** هست که تمام‌صفحه و موبایل‌فرست طراحی شده (بدون هیچ فریم یا نوار وضعیت ساختگی) و آماده‌ست برای:
1. اجرا به‌عنوان یه **PWA قابل نصب روی اندروید** (بدون نیاز به کامپایل)
2. تبدیل به یه **اپ اندروید بومی (APK/AAB)** با Capacitor

## اجرا روی کامپیوتر

```bash
npm install
npm run dev
```

## ساخت نسخه‌ی پروداکشن (وب / PWA)

```bash
npm run build
npm run preview   # برای تست خروجی build
```

خروجی توی پوشه‌ی `dist/` ساخته می‌شه. این پوشه رو می‌تونی روی هر هاست استاتیکی (Vercel, Netlify, GitHub Pages, Cloudflare Pages) آپلود کنی.

## نصب روی اندروید بدون کامپایل (روش سریع - PWA)

بعد از دیپلوی `dist/` روی یه دامنه (حتی GitHub Pages رایگان):
1. سایت رو با **Chrome** روی گوشی اندروید باز کن
2. از منوی سه‌نقطه، گزینه‌ی **«افزودن به صفحه اصلی» / «Install app»** رو بزن
3. اپ دقیقاً مثل یه اپ نصب‌شده، تمام‌صفحه و با آیکون خودش روی گوشی میاد

مانیفست (`public/manifest.json`) و service worker (`public/sw.js`) از قبل برای این حالت آماده شدن.

## ساخت APK واقعی با Capacitor (برای انتشار در گوگل‌پلی یا نصب مستقیم)

```bash
npm install @capacitor/core @capacitor/android
npx cap init "ititube" "app.ititube.android" --web-dir=dist
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

آخرین دستور، پروژه رو توی **Android Studio** باز می‌کنه. از اونجا:
- برای تست سریع: `Run ▶` روی گوشی یا شبیه‌ساز
- برای گرفتن APK: `Build → Build Bundle(s)/APK(s) → Build APK(s)`

> نکته: چون این پروژه با `100dvh` و `env(safe-area-inset-*)` نوشته شده، داخل WebView اندروید هم درست و تمام‌صفحه نمایش داده می‌شه و با نوار وضعیت واقعی گوشی تداخلی نداره.

## آپلود روی گیت‌هاب و آنلاین کردنش (بدون نیاز به خط فرمان)

1. برو [github.com](https://github.com) و وارد حسابت شو (یا یکی بساز)
2. رو دکمه‌ی سبز **New** بزن و یه ریپازیتوری جدید بساز (مثلاً به اسم `ititube-app`) — عمومی (Public) بذارش
3. توی صفحه‌ی ریپازیتوری خالی، رو لینک **uploading an existing file** کلیک کن
4. تمام فایل‌ها و پوشه‌های داخل این پروژه رو (به‌جز پوشه‌های `node_modules` و `dist` اگه وجود داشتن) بکش و بنداز توی همون صفحه
5. پایین صفحه دکمه‌ی **Commit changes** رو بزن

### فعال کردن آدرس آنلاین (GitHub Pages)

1. توی ریپازیتوری برو به **Settings → Pages**
2. زیر «Build and deployment» → «Source» رو بذار روی **GitHub Actions**
3. برگرد به تب **Actions** بالای صفحه — یه ورک‌فلو به اسم «Deploy to GitHub Pages» به‌صورت خودکار اجرا می‌شه (چون این پروژه از قبل فایل `.github/workflows/deploy.yml` رو داره) و خودش پروژه رو build و منتشر می‌کنه
4. بعد از چند دقیقه، توی همون تب Pages یه لینک به شکل `https://username.github.io/ititube-app/` بهت می‌ده

### نصب روی گوشی اندروید

همون لینک بالا رو با **Chrome** روی گوشی باز کن، از منوی سه‌نقطه **«Install app» / «افزودن به صفحه اصلی»** رو بزن — اپ تمام‌صفحه با آیکون خودش نصب می‌شه، دقیقاً مثل یه اپ واقعی.

> هر بار که فایلی رو توی گیت‌هاب عوض کنی و Commit کنی، ورک‌فلو خودش دوباره build و منتشر می‌شه، نیازی به هیچ کار دستی نیست.

## شارژ کیف پول، پشتیبانی و دستیار هوش مصنوعی

- **شارژ کیف پول**: دو روش داره — کارت‌به‌کارت و کریپتو. شماره کارت و آدرس کیف‌پول کریپتو (و آیدی تلگرام پشتیبانی) همه از یک‌جا قابل ویرایش هستن: فایل `src/data/payment.js`. چون این پروژه فقط فرانت‌اند هست و سرور نداره، شارژهای کارت‌به‌کارت/کریپتو به‌صورت خودکار به موجودی اضافه نمی‌شن — کاربر رسیدشو برای پشتیبانی توی تلگرام می‌فرسته و بعد از تایید (که فعلاً باید دستی از بک‌اند/ادمین انجام بشه) موجودی شارژ می‌شه. اگه بعداً بک‌اند اضافه کردی، تابع `handleCharge` توی `src/App.jsx` رو به API خودت وصل کن.
- **پشتیبانی**: دکمه‌ی «راهنما و پشتیبانی» توی تنظیمات و دکمه‌ی «ارسال رسید در تلگرام» توی شارژ کیف‌پول، هر دو به `https://t.me/ititube` می‌رن (قابل تغییر توی همون `src/data/payment.js`).
- **دستیار هوش مصنوعی (ایده‌یاب ویدیو)**: از صفحه‌ی خانه قابل دسترسیه. فعلاً یه موتور ایده‌ی آفلاین و بدون نیاز به API key داره (`src/data/aiIdeas.js`) که بر اساس موضوع کانال، عنوان/هوک/تگ پیشنهاد می‌ده. اگه می‌خوای از یه مدل هوش مصنوعی واقعی استفاده کنی، باید یه بک‌اند کوچیک بسازی که کلید API رو نگه داره (هیچ‌وقت کلید API رو مستقیم توی کد فرانت‌اند/گیت‌هاب پابلیک نذار) و تابع `generateIdeas` رو با یه فراخوانی به همون بک‌اند جایگزین کنی.

## ساختار پروژه

```
src/
  theme.js            رنگ‌ها و فونت برند
  i18n.js              متن‌های سه‌زبانه (fa/en/tr)
  data/packages.js     پکیج‌ها و وضعیت سفارش‌ها
  components/          اجزای مشترک (لوگو، دکمه‌ها، مودال‌ها، ناوبری پایین)
  screens/             صفحات اصلی (ورود، خانه، سفارش، کیف‌پول، تنظیمات)
  App.jsx              مدیریت state و مسیریابی بین صفحات
public/
  manifest.json         مانیفست PWA
  sw.js                  service worker
  icon-*.png             آیکون‌های اپ
```
